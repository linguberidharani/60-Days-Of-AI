# 🚀 Day 50 – Defend Your Experience

## 📌 Overview
Defend Your Experience is an AI-powered Adaptive Interview Defense Simulator that helps users confidently defend every claim made in their resume or portfolio. It extracts experience claims, conducts adaptive interview sessions, tracks confidence, and generates a detailed Defense Report.

## ✨ Features
- AI-Powered Adaptive Interview Simulator
- Resume & Experience Upload
- Automatic Claim Extraction
- Personalized Follow-up Questions
- HR Screening Interview Mode
- Interview Configuration Panel
- Confidence & Progress Tracking
- Defense Report Generation
- Session History
- Local Storage Support
- Responsive SaaS UI
- Dark/Light Mode

## 🛠️ Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
- Claude AI
