# Day 45 – AI Decision Strategist

## 📌 Overview

For Day 45 of the **ABTalks 60-Day AI Challenge**, I built an **AI Decision Strategist**, an interactive web application that helps users make important life and career decisions through structured reasoning instead of emotional guesswork.

The application guides users through a short interview, analyzes multiple decision options, identifies cognitive biases, compares choices using a weighted decision matrix, performs a premortem analysis, generates a 7-day validation plan, and provides a final recommendation with shareable summary cards.

Everything runs completely offline using a single HTML file with LocalStorage support.

---

# 🚀 Features

### 📝 Guided Decision Interview
- 4-step interactive questionnaire
- Progress indicator
- Previous / Next navigation
- Restart functionality
- Smooth user experience

### 🧠 Decision Analysis
- Understands the real decision
- Identifies emotional conflicts
- Explains the core trade-offs
- Measures decision complexity

### ⚖️ Option Analysis
For every decision option:
- Strengths
- Weaknesses
- Hidden opportunities
- Potential risks
- Best-fit user profile
- Recommended personality

### 🔍 Assumption Buster
- Detects hidden assumptions
- Highlights cognitive biases
- Challenges weak reasoning
- Reveals overlooked factors

### 📊 Decision Matrix
Evaluates every option across:
- Career Growth
- Financial Impact
- Learning Opportunity
- Stress Level
- Risk
- Reversibility
- Long-term Alignment

Includes:
- Animated score bars
- Total score comparison
- Best option highlight

### ⚠️ Premortem Analysis
Imagine each decision failed after 12 months.

Shows:
- Why it failed
- Early warning signs
- Prevention strategy
- Recovery plan

### 📅 7-Day Validation Plan
Provides actionable daily tasks:
- Research
- Data collection
- Small experiment
- Expert discussion
- Results comparison
- Reflection
- Final decision day

### 🏆 Final Verdict
Summarizes:
- Recommended option
- Confidence score
- Why it wins
- What could change the recommendation
- Hard truth
- Immediate next action

### 📢 Shareable Cards
Creates ready-to-share cards containing:
- Decision Matrix Summary
- Winning Option
- LinkedIn Caption

### 💾 Additional Features
- Offline support
- LocalStorage persistence
- Dark Mode
- Print Report
- Export as TXT
- Export as Markdown
- Responsive design
- Modern glassmorphism UI
- Smooth animations
