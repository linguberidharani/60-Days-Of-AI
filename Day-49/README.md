# 🚀 Day 49 – Personal AI Playbook

## 📌 Overview
Personal AI Playbook is a modern web application that helps users organize reusable AI workflows instead of managing scattered prompts. It includes a Prompt Builder, Loop Builder, Workflow Library, Productivity Insights, and Import/Export support in a clean SaaS-style interface.

## ✨ Features
- Dashboard with workflow overview
- Workflow Library with search & filters
- Modular Prompt Builder
- Autonomous Loop Builder
- Create, Edit & Favorite Workflows
- Productivity Insights
- Import & Export JSON
- Settings Panel
- Keyboard Shortcuts
- Interactive Onboarding Tour
- Local Storage Support
- Responsive UI
- Dark Theme

## 🛠️ Technologies Used

- CSS3
- Vanilla JavaScript
- Claude AI
