## 🖥️ Application

TRIAGE//44 is a SOC alert classification training platform where users practice classifying security alerts as:

- Malicious
- Benign
- Needs Investigation

The application provides explanations after answers so users can understand why a classification is correct.

## 🛠️ Technology Used

- HTML5
- CSS3
- JavaScript
- ES Modules
- LocalStorage
- Git & GitHub

## 🔐 Architecture

TRIAGE//44 is a lightweight client-side application.

There is:

- No backend
- No database
- No authentication
- No paid API
- No runtime AI dependency

Training data is stored locally and user progress is maintained using browser LocalStorage.
