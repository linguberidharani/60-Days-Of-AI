# Day 47 – Content Intelligence Studio

## 📌 Overview

On Day 47 of the ABTalks 60 Days Claude Challenge, I built **Content Intelligence Studio**, a premium AI-powered web application that analyzes content quality and provides actionable recommendations for creators.

The application follows an interview-driven workflow where the user selects the content type, platform, goal, uploaded content, and review style before generating a detailed AI review.

The project is built as a **single self-contained HTML application** using **HTML, CSS, and Vanilla JavaScript** with a modern SaaS-inspired interface.
