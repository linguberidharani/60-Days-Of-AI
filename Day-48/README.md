# Day 48 – The Verdict Engine

## 📌 Project Overview

For Day 48 of the **#60DayClaudeChallenge**, I built **The Verdict Engine**, an AI-powered comparison and decision-making dashboard that helps users make informed choices by comparing multiple options across customizable criteria.

For this implementation, the application compares **Java vs Python** using real-world references, interactive weight adjustments, visual analytics, and a research transparency panel.
